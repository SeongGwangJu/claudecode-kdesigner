# 케이디자이너 (Claude Code For KDesigner)

> 한국 디자이너가 *git·터미널 지식 없이* Claude Code로 화면을 만들고 개발자에게 깔끔히 넘기는 플러그인. 자연어로 말씀만 하시면 됩니다.

📖 **웹에서 보기 → [seonggwangju.github.io/k-designer](https://seonggwangju.github.io/k-designer/)** (이 README를 잘 디자인된 페이지로)

---

## 이게 뭐죠?

지금까진 보통 이런 식이었죠.

> 디자이너가 *피그마(`Figma`)*에서 화면을 그려요 → 퍼블리셔·개발자가 그걸 *진짜 화면*으로 옮겨요 → 그제서야 만져볼 수 있어요.

중간에 끼어드는 사람이 많고, 디자이너의 *원래 그림*이 옮겨지는 동안 미묘하게 비틀어지기도 합니다. 그리고 *진짜로 클릭해보기*까지 며칠이 걸려요.

**케이디자이너는 그 사이를 지웁니다.** 디자이너가 *키보드 딸깍* 한 줄로 — "이런 카드 3개 가로로 깔아줘" — 진짜로 클릭되고 스크롤되는 화면을 *바로* 만들 수 있어요. 그 결과물은 그대로 개발자에게 넘어가서 *데이터만 진짜 걸면 끝*인 상태가 됩니다.

원래 클로드 코드(`Claude Code`)는 *개발자 도구*예요. 케이디자이너는 그걸 **디자이너 도구로 탈바꿈시키는 플러그인**입니다. 영어 에러·터미널 명령·git 같은 걸 다 가리고, 한국어로만 대화하게 만들어요.

---

## 설치하면 뭐가 좋은데요?

- 🖱️ **만질 수 있는 결과물** — 피그마 시안만이 아니라 *진짜로 스크롤·클릭되는 화면*. 모바일 크기로 줄여보고 다크모드도 켜볼 수 있어요
- 🚀 **0에서 1까지 30분** — 빈 폴더에서 시작해도 30분 안에 화면 1개 + 개발자 인계까지 가능. 회사 프로젝트가 이미 있으면 그 디자인 시스템을 그대로 *이어 받아서* 새 화면을 만들어요
- 🎨 **AI 티 안 나는 디자인** — 보라 그라디언트, Inter·Roboto 폰트, 이니셜 박스 아바타, Lorem ipsum 같은 *AI가 흔히 만드는 클리셰*를 처음부터 자동으로 피해줘요. 좋아하는 디자인·본인 작업을 한 번 답해두면 매번 *내 결*에서 시작
- 🛡️ **실수 방어** — 색·간격 한 곳 바꾸면 *전 화면을 덮치는* 사고를 자동으로 잡아주고 영향 범위를 보여줘요. 영어 에러는 자동 회복부터 시도, 안 되면 한국어로 풀어 설명
- 🧠 **고품질 결정엔 깊이 고민** — 0→1 셋업·디자인 시스템 추출·인계 정리 같은 *디자인 결정 작업*은 케이디자이너가 메인 두뇌로 깊이 고민. 가벼운 명령(저장·서버 켜기·빌드 검증)만 보조 모델로 빠르게 — 비용보다 *디자이너 결과 신뢰도*를 먼저
- 📦 **개발자에게 매끄럽게** — 디자이너가 작업한 그 시점 그대로 `handoff/` 폴더에 *회차별 파일*로 누적. `INDEX.md`가 한눈에 요약, 개발자는 *데이터만 연결*하면서 적용 항목을 체크박스로 추적
- 🇰🇷 **그냥 한국어** — "저장해줘", "보여줘", "더 둥글게" 같은 말 한 줄이면 됩니다. git이나 npm 같은 단어를 알 필요 없어요

설치 한 번이면 매일의 디자인 사이클 — 새 화면 만들기, 점검, 저장, 인계 — 이 *그저 한국어로* 흘러갑니다.

## 처음 쓰시는 분께

### 1단계 — 준비물 깔기 (한 번만)

이 플러그인은 *클로드 코드*라는 도구 위에서, *git*이라는 코드 가져오기 도구를 빌려서 동작합니다. 본인 운영체제 접은글을 펼쳐서 위에서 아래로 *한 번에 쭉* 따라 해주세요.

> ⚠️ **시작 전 — 유료 구독이 필요해요**
> 클로드 코드는 *Claude의 유료 요금제* 위에서만 동작합니다. *무료 Claude.ai* 계정으론 안 돼요.
> - **최소**: *Pro 요금제* (월 $20)
> - **권장**: *Max 요금제* (월 $100 이상) — 디자이너 작업처럼 길게 도는 사이클에선 Pro 한도가 빠르게 소진됩니다
>
> 회사에서 쓰실 거면 IT·관리자 분께 *Pro 또는 Max 자리* 부탁드리세요. 미리 결제·로그인까지 끝내두시면 아래 단계가 매끄럽게 흘러갑니다.

<details>
<summary><b>🍎 맥(macOS)에서 한 번에 쭉 — 약 10분</b></summary>

#### 1) 터미널 열기

*런치패드*(Launchpad)에서 **`터미널`** 검색해서 열기. 검은 창이 뜨면 OK.

#### 2) git 설치

터미널에 다음 한 줄 붙여 넣고 ↵Enter:

```bash
xcode-select --install
```

설치 창이 뜨면 *Install* 버튼 → *동의* → 기다리기 (약 5~10분, 진행바 천천히 움직여도 정상).

설치 끝나면 확인:
```bash
git --version
```
→ `git version 2.x.x` 같은 숫자 줄이 뜨면 통과.

#### 3) 클로드 코드 설치 (Anthropic *권장* 방식)

터미널에 다음 한 줄:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

자동으로 받아져요 (1~2분). 끝나면 확인:

```bash
claude --version
```

#### 4) 첫 로그인

```bash
claude
```

치는 순간 *브라우저 창*이 뜨면서 로그인하라고 합니다. 본인의 *Pro/Max 계정*으로 로그인하면 이쪽 터미널 화면으로 자동 돌아와요.

#### 5) 확인

`claude` 실행 후 검은 화면 안에 입력 칸이 뜨고 인사말이 보이면 **준비 완료**. 이 상태에서 *2단계*로 가시면 됩니다.

### 2단계 — 이 플러그인 설치

1단계 끝에 `claude`로 켜둔 *그 화면*에서 그대로 진행합니다. (혹시 닫으셨다면 터미널 다시 열고 `claude` 한 번 더)

켜진 화면에서 다음 두 줄을 차례로 입력하세요. (앞에 `/` 그대로 붙여서)

```
/plugin marketplace add https://github.com/SeongGwangJu/claudecode-kdesigner.git
/plugin install kdesigner@claudecode-kdesigner
```

첫 줄이 *플러그인 카탈로그를 등록*, 둘째 줄이 *실제 설치*입니다.

#### 설치 중간에 이런 화면이 뜨면

```
> Install for you (user scope)
  Install for all collaborators on this repository (project scope)
  Install for you, in this repo only (local scope)
```

→ **첫 번째 항목 (`Install for you`, user scope) 권장**. *내 컴퓨터 어느 폴더에서든* 디자이너 모드로 작동합니다. (회사 동료와 함께 쓸 거면 두 번째, 이 한 폴더에서만 쓸 거면 세 번째)

#### 설치 중간에 이런 경고가 뜨면

```
⚠ Make sure you trust a plugin before installing...
Will install:
· Component summary not available for remote plugin
```

→ 정상입니다. *원격에서 가져오는 플러그인은 미리보기가 안 뜨는 게 기본*이에요. 그대로 진행하세요.

#### 설치 완료 확인

설치가 성공하면 이런 메시지가 뜹니다:

```
✓ Installed kdesigner. Run '/reload-plugins' to apply.
```

→ 메시지 그대로 **`/reload-plugins`** 한 줄을 그 다음에 입력해주세요. 그래야 방금 깐 플러그인이 *바로 이 자리에서* 활성화돼요. (안 치면 클로드 코드를 한 번 껐다 켜야 잡힙니다)

`/reload-plugins`까지 끝내면 명령어 자동완성에 `/kdesigner:`로 시작하는 것들이 잡히기 시작해요.

### 3단계 — 시작 의식 (한 번 + 매 프로젝트마다 한 번)

시작 의식은 *두 단계*예요. 한 번 익히면 평생 매 프로젝트마다 같은 흐름.

**(1) `/kdesigner:맨처음설정` — *이 컴퓨터에 처음 한 번만***

```
/kdesigner:맨처음설정
```

`/`만 친 다음 *맨*까지만 쳐도 자동완성에 잡혀요. 이 컴퓨터 전체에서 디자이너 모드를 켤지 한 번만 물어봅니다 — *잘 모르겠으면 권장(이 컴퓨터 전체에서 켜기)*이 편해요. 켜고 나면 어느 폴더로 가도 한국어·디자이너 톤으로 자동 작동.

**(2) `/kdesigner:프로젝트시작` — *작업 폴더 들어갈 때마다***

```
/kdesigner:프로젝트시작
```

이 프로젝트의 사실(서비스명·디자인 토큰·컴포넌트 목록 등)을 박아드려요. *`DESIGN.md`* (디자인 시스템 명세 표준 파일, `https://getdesign.md/`)가 폴더에 있으면 자동으로 1순위 소스로 인식. 빈 폴더면 *새 디자인 시작*, 기존 코드가 있으면 *기존 프로젝트 가져오기*로 자연스레 이어집니다.

### 4단계 — 자연어로 시작

> "새로 만들고 싶어" 또는 "기존 프로젝트에서 가져오기"

응답 끝에 따라오는 *다음 행동 제안*만 따라가시면 30분 안에 화면 1개 + 개발자 인계까지 됩니다.

## 이렇게 말하면 동작해요

자연어 한 줄이면 알아서 흘러갑니다. 슬래시는 비상용이니 평소엔 무시하세요.

| 이렇게 말씀하시면 | 무슨 일이 일어나요 |
|---|---|
| "새로 만들고 싶어" / "처음부터 만들어줘" | 빈 폴더에서 새 프로젝트를 셋업하고 첫 화면 만들 준비까지 끝냅니다 |
| "기존 프로젝트에서 가져오기" | 회사 코드에 안전하게 끼어들어 컴포넌트를 정리해드려요 (기존 파일은 손대지 않아요) |
| "보여줘" / "한번 띄워봐" / "화면 켜줘" | 의존성 설치·서버 시작·브라우저 열기까지 한 번에 |
| "저장해줘" / "임시저장" / "올려줘" | 지금까지 작업을 한 시점으로 묶어둡니다 (나중에 그 시점으로 되돌릴 수 있어요) |
| "점검해줘" / "확인해줘" | 모바일 잘림·색 대비·이미지 설명 누락·디자인 토큰 어긋남을 사람 말로 짚어드려요 |
| "팀에 보여줄게" / "클라이언트한테 시안 보내줄게" / "링크 만들어줘" | 안전 점검(빌드·민감정보·더미 데이터) 후 *외부 공유 가능한 URL*을 만들어드려요. 잠깐 보여주기·며칠 시안·지속 공유·공개 중 의도 1번만 묻고 자동 분기. 회사 프로젝트면 보안 가드도 한 번 더 |
| "이제 내려줘" / "그만 보여줘도 돼" | 공유 정리. 외부에 떴던 링크를 깔끔히 내리고 이력에 *종료* 표시 |
| "개발자한테 넘기기" / "인계 정리해줘" | 개발자가 1분 안에 알아볼 수 있게 `handoff/{날짜-주제}.md` *회차 파일* 1개 + `handoff/INDEX.md` 한눈 요약 자동 갱신. 각 항목 `- [ ]` 체크박스 (이전 외부 공유 이력 있으면 INDEX에서 함께 참조) |
| "최신화해줘" / "본 레포에서 가져오기" / "원본 변경분 가져와줘" | 회사 레포(원본)에 *그 사이 개발자가 추가한 변경*을 디자인 영역만 골라 가져옵니다. 백엔드 같은 *개발자 영역*은 손대지 않고 알림만 — 충돌나면 안전하게 되돌리고 *어떤 쪽 우선*인지 한 번 묻습니다 |
| "이 버튼 좀 더 둥글게" / "색 부드럽게" | 이 화면만 바꿀지, 전체에 적용할지 자동으로 묻고 일관성을 지켜드려요 |
| "에러 났어" / "왜 안 돼?" | 영어 에러는 자동 회복부터 시도, 안 되면 친화 한국어 + 개발자에게 보낼 메시지를 따로 만들어드려요 |

> 💡 **표 외우지 않으셔도 돼요.** 응답 끝에 항상 *다음에 어떤 자연어를 쓰면 되는지*를 함께 알려드립니다.
>
> 💡 **저장의 의미 — 되감기 책갈피.** "저장해줘" 한 번 = *되감기 책갈피* 하나. 너무 자주 만들면 책갈피끼리 비슷해지고, 너무 안 만들면 어디로 되감을지 모르게 돼요. *의미 묶음*(예: "메인 화면 카드 다듬기")이 끝났다 싶을 때 한 번씩이 적당합니다.

## 기존 프로젝트 가져올 때 — 4가지 입력 종류

회사 코드를 받았을 때 *그 종류*에 따라 다른 흐름으로 처리됩니다. "기존 프로젝트에서 가져오기"라고 말씀하시면 자동 판정 + 1번만 확인.

| 종류 | 어떤 모습 | 케이디자이너가 하는 일 |
|---|---|---|
| **A. 전체 레포** | 운영 중인 서비스 코드 통째 (`package.json` + 라우트 + 백엔드 API + 인증) | **디자인 모드로 변환** — 인증·API를 *가짜 모듈*(`mock/`)에 격리해 백엔드 없이도 화면이 뜨게. 운영 코드(`middleware*`/`app/api/**`/`lib/**`)는 *손대지 않아요* |
| **B. 디자인 + 페이지 추출분** | 컴포넌트 + 일부 페이지 (`package.json` 부분/없음) | 부족한 부분(의존 컴포넌트·토큰·미니 셋업) 채우기 |
| **C. 디자인 시스템만** | 토큰 + 기본 컴포넌트, 페이지 없음 | "이 시스템으로 어떤 화면 만들고 싶으세요?" → *새 디자인 시작* 흐름으로 합류 |
| **D. 컴포넌트 일부** | 단편 컴포넌트만 | 부분 환경 셋업 + 한계 안내 1줄 |

> 💡 **A 분기 — 운영 레포 변환의 안전 원칙**
> 인증 우회·API mock·더미 데이터는 *백엔드 영역 코드 안*에 분기를 박지 않아요. 대신 `mock/auth-stub.ts`·`mock/api-stubs/`·`lib/design-mode/` *별도 모듈*에 격리하고, *컴포넌트 import 줄*에서만 디자인 모드 토글로 분기. 그래야 나중에 본 레포에 *그대로 반영* 가능하거나 *쉽게 떼어낼 수* 있어요.
>
> 변환 후엔 `pnpm dev:kd-design`(또는 npm/yarn) 한 줄로 디자인 모드 실행 — 프레임워크에 맞게 자동 셋업.

> 📍 **어디서 실행해야 할까요?**
> *프로젝트 루트*(`package.json`이 있는 폴더)에서 `/kdesigner:프로젝트시작`을 부르는 게 가장 자연스러워요. 하위 폴더에서 실행하면 *루트로 이동할지 / 여기서 떼어내 작업할지* 한 번 묻습니다.

**페이지 단위 자동 인덱싱** — Next.js App/Pages Router, Vite + React Router, Expo Router, SvelteKit, Astro 등 *프레임워크별 라우트 패턴*을 케이디자이너가 자율 탐지해서 *사용 가능한 페이지* 목록을 `CLAUDE.project.md`에 정리해드려요. 어떤 페이지부터 손볼지 한눈에 볼 수 있어요.

## 만들어지는 폴더 약속

새로 만들거나 가져온 프로젝트엔 다음 폴더가 자동으로 생깁니다.

- `asset/` — 이미지·아이콘·폰트
- `mock/` — 가짜 데이터 (개발자가 실제 데이터로 교체할 자리)
- `components/` — 재사용 컴포넌트

자연어 "이 이미지 추가해줘"는 자동으로 `asset/`에 들어가고 컴포넌트에서 바로 참조됩니다.

## 디자이너가 안전하게 작업할 영역

운영 중인 회사 레포에서도 *어디까지 손대도 안전한지*를 케이디자이너가 자동으로 가드해드려요. 두 단계로 동작:

### 1단계 — 파일 단위 안전망 (조용히 막거나, 묻거나)

| 자유롭게 손대도 OK | 묻고 진행 (개발자 영역) |
|---|---|
| `components/` (재사용 컴포넌트) | `middleware.*` (요청 가로채기) |
| `app/`·`pages/` (라우트 페이지) | `app/api/**` (백엔드 API) |
| `mock/` (가짜 데이터) | `lib/` (런타임 로직, 단 `lib/design-mode/`는 OK) |
| `lib/design-mode/` (디자인 모드 전용) | `hooks/` (커스텀 훅) |
| `asset/`·`public/` (이미지·아이콘) | `stores/` (전역 상태) |
| `tailwind.config.*`·`globals.css`·`styles/` (디자인 토큰) | `config/navigation*` (라우팅 메타) |
| `.env.kdesigner-design` (디자인 모드 전용 환경변수) | `package.json`·`tsconfig.*`·`.env*` (프로젝트 설정) |

개발자 영역에 손대려고 하면 케이디자이너가 *조용히 막고* "여기 손대고 싶으세요?" 한 번 묻습니다. 동의하시면 진행 + 인계 노트에 자동 기록(개발자가 검토할 수 있게).

### 2단계 — 변경 *종류* 가드 (디자이너 영역 안이라도)

`components/`나 `app/` 안에서도 *디자인 표현 외* 변경은 톤을 차별화해드려요.

- **(a) 격리 OK** — 디자인 모드 토글 안 변경·Tailwind 클래스·CSS 변수만 변경 → *조용히 통과* ("디자인 모드 토글이 깨끗하게 격리됐어요" 한 줄 인지)
- **(b) 격리 부족** — 디자인 모드 의도인데 토글 검사가 빠짐 → *보강 제안* ("`if (IS_DESIGN_MODE)` 블록 안으로 옮길까요?")
- **(c) 진짜 영향** — 컴포넌트 사용법 변경(`props` 줄)·도메인 훅 import·상태 흐름 훅 신규·`<Link>` 제거 같은 *디자인 외 영향* → *명시 동의* + 인계 노트에 자동 기록

> 💡 **차단보다 분리·기록 우선.** 디자이너 흐름은 끊지 않아요. 의도하신 변경이면 진행 + 다음 인계 회차 파일(`handoff/{...}.md`)의 *⚠️ 디자인 외 변경 — 검토 필요* 섹션에 자동으로 올라가요. 개발자가 그 항목만 체크하면 됩니다.

### 본 레포 구조에 안 맞으면

`CLAUDE.project.md`의 *디자이너 작업 영역 경계* 섹션에서 허용/금지 경로를 *프로젝트별로* 조정할 수 있어요. 개발자분께 한 번 봐달라고 부탁드리시면 좋아요.

## 자동으로 막아주는 다른 위험

- **에러 자동 회복** — *필요한 도구 누락*(영어로 `dependency missing`)·*화면 출력 통로 충돌*(영어로 `port in use`)·일시적 네트워크 오류는 자동으로 다시 시도합니다. 영어 에러를 그대로 던지지 않아요
- **저장 직전 검증** — 큰 작업 마무리 시 자동으로 한 번 점검을 돌립니다. 텍스트 사소한 변경엔 발동 X (시간 낭비 없이)
- **디자인 토큰 일관성** — 한 화면에서 시작한 색·간격 변경이 *전 화면을 덮치는* 사고를 막아드려요. 영향 범위(예: "이 색은 다른 3곳에서도 쓰여요")를 보여주고 묻습니다

## 개발자에게 넘길 때

"개발자한테 넘기기"라고 말씀하시면 **회차별 별도 파일**이 자동으로 생깁니다 — `handoff/{YYMMDD-HHmm KST}-{주제}.md` 형식(예: `handoff/260512-1430-메인-화면-카드-다듬기.md`). `handoff/INDEX.md`가 전체 회차 요약을 자동 갱신해요. 각 회차 파일엔:

- **실제 데이터에 연결해야 할 곳** (파일·줄 번호 단위, `- [ ]` 체크박스)
- **이번 사이클에 새로 도입한 데이터 hook**
- **가짜 데이터 위치**와 실제 API가 가져야 할 형태 힌트
- **⚠️ 디자인 외 변경 — 검토 필요** — 디자이너가 명시 동의 후 진행한 prod 영향 변경
- **알려진 이슈** (점검에서 발견한 노랑)
- **회차 시점의 저장 표식** (`commit 해시`) — 개발자가 정확히 그 시점을 다시 볼 수 있게

개발자분께 `handoff/INDEX.md` 링크만 보내드리면 거기서 각 회차로 들어갑니다. *공유 이력*(있다면) — 이 디자인이 클라이언트·팀에 누구에게 언제 보였는지도 INDEX에서 함께 참조.

> 💡 **인계는 여러 번, 개발자는 부분 적용.** 한 번에 다 넘기지 않아도 돼요. 작업 흐름 단위로 자주 넘기시면 *시간순 파일들*이 흐름을 보존하고, 개발자는 각 회차에서 적용한 항목만 `- [x]`로 체크. 다음 인계 시 미적용 카운트가 자동으로 줄어듭니다.

> 💡 **인계와 *외부 공유*는 다릅니다.**
> - **개발자한테 넘기기** = *단방향 전달* (개발자가 받아서 실서비스에 통합)
> - **팀에 보여줄게 / 클라이언트한테 시안** = *양방향 피드백* (외부에서 보고 의견 줌)
> 같은 사이클 안에서 둘 다 쓸 수 있어요 — 시안 검토받고 → 수정 → 인계 흐름이 자연스럽습니다.

## 비상용 슬래시 커맨드 ⚠️

자연어가 발동되지 않거나 위험 동작을 명시적으로 트리거하고 싶을 때만 씁니다. 평소에는 무시하세요.

- `/kdesigner:맨처음설정` — 이 컴퓨터에 *처음 한 번만* 켜는 의식. 전역으로 켤지 묻습니다
- `/kdesigner:프로젝트시작` — 매 프로젝트마다 한 번. *이 프로젝트의 사실*(컴포넌트·토큰)을 박고 `DESIGN.md` 있으면 자동 인식
- `/kdesigner:디자인끄기` — 디자이너 모드 종료. 전역 설정도 *원본 그대로* 복원
- `/kdesigner:되돌리기` — 작업 되돌리기. *되돌리기*(`git revert`) 기반이라 되돌린 것도 다시 되돌릴 수 있어요 (안전)

> 💡 **팁**: `/`만 친 다음 뒷부분(예: *맨*, *프로*, *끄기*, *되돌*)만 쳐도 자동완성이 잡아줍니다. 굳이 `/kdesigner:`를 다 칠 필요 없어요.

## 잘 안 될 때

- **자연어로 말했는데 발동 안 함** — 같은 동작을 슬래시로도 부를 수 있어요. "보여줘"가 안 먹으면 작업 폴더에서 `/kdesigner:프로젝트시작`을 한 번 부르셨는지 먼저 확인하세요 (켜져 있다면 표현을 살짝 바꿔서 다시)
- **영어 에러가 그대로 보임** — 자동 회복이 실패한 경우입니다. 화면에 같이 뜨는 *개발자에게 복사해 보내주세요* 블록을 그대로 개발자에게 전달해주세요. 본문은 한국어로 정리되어 있어요
- **명령어가 안 보여요** — 클로드 코드 *재시작* 한 번 해보세요. 설치 직후엔 새 명령어가 잡히는 데 시간이 좀 걸리기도 합니다
