# 업계 일반 시각 안티패턴 (회피 우선)

> 이 목록은 *외부 검증 가능한 업계 일반 클리셰*다. 디자이너 1명 사례·특정 회사 결이 아니다 — *어디서나 흔하게 발견되어 식별성이 떨어지는 결*만 박았다. 한국 디자이너 시각에서 *AI/SaaS 클리셰로 인지되는 빈도*가 높다는 게 일반화 근거.
>
> 사용 방식 — *고정 차단 X*. 한 방향 commit 결정 시 *디폴트 회피* 후보로 참조. 디자이너 의도·프로젝트 톤이 명시적으로 그 결이면 그대로 진행 (예: 의도된 *플레이풀* 톤에서 이모지 사용 OK).

## 1. shadcn 기본 슬레이트 팔레트 그대로

**현상**: `bg-slate-*`·`text-slate-*` 디폴트 회색 톤만 사용, 프로젝트 색 결정 *없이*.

**왜 안티**: 디폴트 슬레이트는 *모든 shadcn 프로젝트의 공통 출발선*이라 *식별성 0*. *디자인 결정의 부재*가 그대로 화면에 드러난다.

**회피 결**: 톤 한 단어(`CLAUDE.project.md` §project-tone)에 맞춰 *최소 1색 결정* 후 시작 — 회색조도 *어떤 회색*인지(차가운/따뜻한·고대비/저대비) 선택.

## 2. Vercel/Linear 클론 결 (중앙 정렬 + 큰 hero + 큰 CTA + 4-아이콘 카드)

**현상**: 풀스크린 hero + 중앙 정렬 헤딩 + 그 아래 큰 그라디언트 CTA + lucide-react 아이콘 4개 균등 그리드.

**왜 안티**: 2020년대 후반 SaaS 랜딩의 *집단 클리셰*. *어떤 서비스인지* 화면에서 읽히지 않고 *어떤 도구로 만들었는지*만 드러난다.

**회피 결**: 서비스 *고유한 결*(에디토리얼 매거진·브루탈리스트·유기체·산업적 등) 1방향 commit → 그 결로 hero·CTA·아이콘 처리. 4-아이콘 균등은 *밀도·크기·정렬 비대칭* 1번이라도 깨기.

## 3. 이모지 헤딩 (✨🚀💡 + 한국어 문장)

**현상**: "✨ 새로운 경험"·"🚀 빠른 시작"·"💡 똑똑한 추천" 같은 *이모지 + 한국어 카피* 패턴.

**왜 안티**: AI 글쓰기 *전형 클리셰*로 인지되는 빈도가 높다 — 한국 디자이너 시각에서 *카피 톤 통일성을 깨는 첫 신호*. 무게감·신뢰감이 필요한 한국 서비스 카피와 자주 어긋난다.

**회피 결**: 헤딩은 *글자만*. 이모지가 정말 필요하면 *카피 본문 일부*로 자연 삽입(헤딩 X). 의도된 *플레이풀* 톤이면 예외 — 그땐 *전체 카피*가 그 결로 통일.

## 4. 그라디언트 텍스트 (특히 보라/핑크/파랑)

**현상**: 헤딩에 `bg-gradient-to-r from-purple-* via-pink-* to-blue-*` + `bg-clip-text text-transparent`. 2020년대 SaaS 헤딩 클리셰.

**왜 안티**: *기본 그라디언트 색 조합*(보라·핑크·청록)이 *AI 생성물 표지*로 빠르게 인지된다. 텍스트 가독성도 낮아 본문 시선이 흩어진다.

**회피 결**: 헤딩은 단색 — 강조하려면 *크기·굵기·여백·줄바꿈*으로. 그라디언트가 정말 필요하면 *배경·아이콘*에만, 텍스트엔 X.

## 5. 균등 4-그리드 통계 카드 + 추상 수치

**현상**: "10K+ 사용자 / 99.9% 가동률 / 50+ 통합 / 24시간 지원" 같은 *추상 수치 4개를 균등 카드*로.

**왜 안티**: 수치가 *추상적이라 검증 불가능*하고, 균등 4-그리드는 *카피 톤 차이*를 0으로 만든다 → 화면 전체가 *같은 무게의 노이즈*가 된다.

**회피 결**: 통계는 *1개만 크게* 또는 *비교 가능한 수치*(예: "5분 → 1분")로. 4-그리드 자체를 의심 — 정말 4개가 *대등한 무게*인지, 아니면 1+3·2+2 비대칭이 더 맞는지.

## 6. 한글 본문에 Inter 폰트 단독

**현상**: `font-family: Inter, sans-serif`로 한글 본문 렌더링. shadcn 디폴트 + Tailwind 디폴트가 이쪽으로 미끄러진다.

**왜 안티**: Inter는 *라틴 자형* 최적화 — 한글 자모 렌더링이 *Noto Sans CJK fallback*으로 떨어지면서 행간·자간·크기 균형이 깨진다. 한국 서비스 시각 품질의 *1차 기준선*이 무너지는 자리.

**회피 결**: Pretendard / SUIT / Spoqa 등 한글 친화 폰트를 *기본*으로. Inter는 *영문 단독 자리*(코드·숫자 mono)에서만 fallback 형태로.

## 7. 디자인 시스템 미정 상태에서 다크 모드 토글 단독

**현상**: 색·간격·둥글기 기준이 *아직 박히지 않은* 화면에 우상단 다크 모드 토글만 추가.

**왜 안티**: 다크 모드는 *기준 색 시스템 위*에서만 일관 — 기준 없이 토글만 박으면 *밝은 화면 ↔ 어두운 화면* 둘 다 *임시 결*이 된다. 형식만 있고 시스템이 없는 결.

**회피 결**: 라이트 모드 색·대비·계층이 *먼저 결정*된 뒤 다크 모드. 첫 시안에 토글 X — *기준이 박힐 때까지 모노 모드*.
