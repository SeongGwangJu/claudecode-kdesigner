> **[필수 사전 체크 — 응답 생성 전에]**
>
> 1. `Read ~/.claude/CLAUDE.md` 시도.
> 2. **마커(`<!-- kd:designer-mode:start -->`) 발견** — *이미 켜져 있음*. 다른 응답 만들기 전에 [references/맨처음설정-마이그레이션.md](./references/맨처음설정-마이그레이션.md) 분기를 처음부터 끝까지 따라간다. 절대 만들지 않는 응답: "이미 켜져 있어요 — 다시 끄려면 `/kdesigner:디자인끄기`로..." 같은 *분기 차단*. 막지 말고 §5.4 패턴 중 하나로 *처리 결과*를 말한다.
> 3. **마커 부재 또는 파일 부재** — §0부터 정상 흐름.
>
> **이 슬래시는 *프로젝트 단위 작업을 하지 않는다*** — `CLAUDE.project.md` 생성, archived 복원, 사이클 SHA, 빈/기존 분기, DESIGN.md 통합 — 모두 `/kdesigner:프로젝트시작` 책임. 헷갈리면 §5 끝의 다음 행동 1개로 `/프로젝트시작` 권유.

# 맨처음설정

## 언제 쓰나

디자이너가 *이 컴퓨터에서 처음으로* 디자이너 모드를 켤 때. 한 사용자 환경에서 *1번만* 실행하는 의식 — 켜고 나면 모든 프로젝트에서 한국어·비유·다음 행동 1개 제안 등 페르소나가 자동 작동. 이후 매 프로젝트마다 `/kdesigner:프로젝트시작`으로 *그 프로젝트의 사실*만 박으면 된다.

## 동작

### 0. 사전 도구 확인

디자이너 모드 작동에 필요한 도구 확인. 다 있으면 짧은 한 줄 후 §1로. 빠진 게 있으면 *어떻게 깔지* 한국어로 친절히 안내하고 흐름을 *멈춘다* — 사용자가 설치/설정 후 `/kdesigner:맨처음설정` 다시 호출.

먼저 `uname -s`로 OS 판별(`Darwin` = macOS). 안내가 OS에 따라 갈라진다.

| 항목 | 명령 | 분류 |
|---|---|---|
| 화면 엔진 (`Node.js`) | `node --version` | 필수 |
| 작업 시점 저장 도구 (`git`) | `git --version` | 필수 |
| 사용자 표시 정보 | `git config --global user.name` + `user.email` | 필수 |
| 도구 설치 도우미 (`Homebrew`) | `brew --version` | macOS 권장 |
| 팀 공유 공간 도구 (`gh`) | `gh --version` | 선택 (인계 단계) |
| 팀 공유 로그인 | `gh auth status` | 선택 |

검사 결과는 *한꺼번에* 모은다 — 사용자가 한 번에 무엇을 깔지 알 수 있게.

**모든 도구 OK**: 진행 단계 가시화 한 줄 후 §1으로.

**필수 도구 누락 → 흐름 정지 + 친화 안내**:
영어 에러 한 줄도 노출 X. *해당하는 항목만* 묶어 한 응답.

OS·brew 분기:
- `Darwin` + `brew` 성공 → brew 경로 메시지 우선
- `Darwin` + brew 없음 → macOS brew 없음 fallback
- Windows / Linux → 공식 사이트 fallback

각 도구별 *그대로 노출할* 한국어 메시지·`AskUserQuestion`(이름·이메일)·흐름 정지 응답 끝 안내는 [references/tool-check-messages.md](./references/tool-check-messages.md).

**선택 도구 누락** — `gh` 미설치·`gh auth status` 실패: 한 줄만 본문 위에 노출 후 *필수 도구가 다 있다는 전제로* §1로.

### 1. 전역 마커 점검

`Read ~/.claude/CLAUDE.md`로 분기 결정:

| 상태 | 분기 |
|---|---|
| 마커 발견 | §5 마이그레이션 ([references/맨처음설정-마이그레이션.md](./references/맨처음설정-마이그레이션.md)) |
| 파일 있지만 마커 없음 | §2 정상 흐름 (백업 후 마커 격리 append) |
| 파일 부재 | §2 정상 흐름 (빈 백업 마커 후 새로 생성) |

### 2. 전역 활성화 — 1회 동의

전역 `~/.claude/CLAUDE.md`에 디자이너 페르소나를 박는다. 강제 X — 1회 동의받되 *왜 권장인지* 옵션 카피에 명시.

> 디자이너 모드를 **이 컴퓨터 전체**에서 켜둘까요?
>
> **켜두면 뭐가 좋나요**: 어느 폴더로 가도 Claude Code가 *처음부터* 한국어로 답하고, 흔한 AI 화면(보라 그라디언트·Inter 폰트·이니셜 아바타 같은 클리셰)을 자동으로 회피하고, 디자이너 친화 톤으로 동작해요. *이 컴퓨터의 Claude Code가 디자이너용 도구로 변하는* 거예요.
>
> **무엇이 바뀌나요**: `~/.claude/CLAUDE.md` 끝에 디자이너 페르소나가 추가돼요(원본 그대로 백업).
> **언제 되돌리나요**: `/kdesigner:디자인끄기` 한 번이면 원본 그대로 복원돼요.
>
> - **이 컴퓨터 전체에서 켜기 (권장)** — 모든 프로젝트에서 자동
> - **이번엔 안 켜두기** — 프로젝트 단위(`/kdesigner:프로젝트시작`)만. 나중에 다시 `/맨처음설정`으로 켜도 OK
> - **잘 모르겠어요** → 기본값: 이 컴퓨터 전체에서 켜기

### 3. 전역 추가 + 백업 (켜기 선택 시)

*켜기* 또는 *잘 모르겠어요*:

1. **백업** — `~/.claude/CLAUDE.md` 있으면 `~/.claude/CLAUDE.md.kd-backup-<YYYYMMDD-HHmm>`로 `cp`. 없으면 빈 백업 마커(`~/.claude/.kd-no-prior-claude-md`).
2. **추가** — `plugin/templates/CLAUDE.user.md` 내용을 `~/.claude/CLAUDE.md` 끝에 *append*. 마커 격리:
   ```
   <!-- kd:designer-mode:start -->
   ... (templates/CLAUDE.user.md 내용)
   <!-- kd:designer-mode:end -->
   ```
   `/kdesigner:디자인끄기`가 이 마커 사이만 잘라 복원할 수 있게.
3. 백업 경로를 응답 1줄로 — "원본은 `~/.claude/CLAUDE.md.kd-backup-YYYYMMDD-HHmm`에 보관해뒀어요".

*이번엔 안 켜두기*: 전역 파일 *건드리지 않음*. §4 검증 스킵하고 §6 다음 흐름 안내. 첫 `프로젝트시작` 시점에 *프로젝트 단위 페르소나 요약*이 `CLAUDE.project.md` 끝에 박혀 단독 동작 지탱.

### 4. 검증 — 마커·백업 확인

- `~/.claude/CLAUDE.md`에 시작·끝 마커 쌍이 *정확히 1개*인지 `Read` 확인. 2쌍 이상이면 중복 → 마지막만 남기고 경고.
- `.kd-backup-*` 백업 생성됐다면 그 경로 응답 1줄.

### 5. 이미 켜져 있을 때 — 마이그레이션

전역에 마커가 이미 있다면 *막지 않고* 슬롯 manifest 기반 idempotent 마이그레이션. 슬롯 4-way 분류·마커만 삽입·빈 골격 추가·결과 응답 4 패턴·안전 장치는 [references/맨처음설정-마이그레이션.md](./references/맨처음설정-마이그레이션.md).

핵심 원칙:
- *자급식 manifest* — `templates/` 외부 Read X. 디자이너 환경에서 그 경로 resolve 실패.
- *사용자 본문 보존 1순위* — 마커 한 줄 삽입과 *진짜 빠진 슬롯*만 추가.
- *손상 의심 즉시 중단* — 백업 + 슬롯 ID 명시 보고.

### 6. 다음 흐름 안내

응답 본문에 (정상·마이그레이션 모두):
> 이제 작업 폴더에서 `/kdesigner:프로젝트시작`을 부르시면 *이 프로젝트의 사실*(서비스명·디자인 토큰·컴포넌트 인덱스 등)을 박아드려요.

§3 *이번엔 안 켜두기*였다면 추가:
> 전역은 안 켜뒀어요 — `/프로젝트시작`이 *프로젝트 단위 페르소나 요약*까지 박아서 단독 동작해요.

## 안전 장치

- **명시 동의** — `~/.claude/CLAUDE.md` 수정 전 `AskUserQuestion` 1회. "무엇이 어떻게 바뀌는지" 1줄 + "잘 모르겠어요" 옵션.
- **백업 우선** — 전역 추가 전 *반드시* `cp`. 실패 시 추가 X.
- **마커로 격리** — `<!-- kd:designer-mode:start -->`~`end`로 `/kdesigner:디자인끄기`가 정확히 그 부분만 제거.
- **재실행 안전** — 마커가 이미 있으면 §5 분기 (idempotent).
- **비파괴** — 사용자 파일 *지우지 않음*. 추가·백업만.
- **외부 도구 호출 금지** — `git`/`npm`/네트워크 X. 이 명령은 *전역 페르소나 켜기*만.
- **프로젝트 단위 작업 금지** — 모두 `/kdesigner:프로젝트시작` 책임.

## 응답 끝

상황별 다음 행동 1개:
- 새로 켰음: "이제 작업 폴더에서 **`/프로젝트시작`** 한번 불러볼까요?"
- 마이그레이션 완료: "작업 폴더에서 **`/프로젝트시작`** 부르시면 이어서 갈 수 있어요."
- 이미 최신: "작업 폴더에서 **`/프로젝트시작`** 으로 그 프로젝트의 사실을 박아볼까요?"
- *안 켜두기*: "전역은 안 켜뒀어요. **`/프로젝트시작`** 만으로도 작동해요."
